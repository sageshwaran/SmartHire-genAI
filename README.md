# SmartHire GenAI

An end-to-end Generative AI career portal: parses a resume, finds matching jobs
via semantic search, generates CV improvement suggestions, and answers career
questions through a RAG-based AI Career Mentor.

## Setup
1. Clone the repo
2. Create a virtual environment: `python -m venv venv`
3. Activate it and run `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and add your API keys
5. Run the app: `streamlit run app/streamlit_app.py`
